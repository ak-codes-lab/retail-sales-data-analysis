# Retail Sales Data Analysis

## Project Overview
This project focuses on analysing retail sales data using Python. It helps understand sales performance, product demand, regional sales and monthly sales trends.

## Objectives
- Analyse total sales revenue.
- Identify the best-selling products.
- Compare sales across different regions.
- Analyse sales by product category.
- Understand monthly sales trends.
- Create an interactive sales dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## How to Run the Project

1. Install the required libraries:
   `pip install -r requirements.txt`

2. Run the analysis:
   `python main.py`

3. Run the dashboard:
   `streamlit run dashboard/app.py`

## Conclusion
This project provides insights into retail sales performance through data analysis and visualisation. The interactive dashboard helps users understand sales trends and business performance.
